这份指南说明模板用到的工具、它们之间的配合方式，以及每个目录和配置文件的用途。

## 概念

- [命令行与 unh](./concepts/cli) — `dev` / `build` 背后做了什么，平台参数怎么传。
- [uni-app 开发](./concepts/uniapp-development) — 模板在 uni-app 之上补充了哪些能力。
- [TypeScript](./concepts/typescript) — 类型来源、类型检查和自动生成的声明文件。
- [自动导入](./concepts/auto-import) — 装插件后省掉组件和 API 的 `import`。
- [路由中间件](./concepts/middleware) — 跳转前的登录校验、权限判断和埋点。
- [按平台开发](./concepts/platform) — 平台文件、平台修饰符、UnoCSS 平台变体。
- [测试](./concepts/testing) — Vitest 和小程序自动化测试。
